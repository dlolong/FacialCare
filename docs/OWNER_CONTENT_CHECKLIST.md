# Owner Content Checklist

Use this before replacing demo content.

## Brand
- [ ] Official high-resolution logo
- [ ] Approved brand colors / fonts
- [ ] Approved tagline usage
- [ ] Approved corporate photography

## Company
- [ ] Official company description
- [ ] Company history
- [ ] Corporate contact details
- [ ] Official Facebook / Instagram / TikTok links

## Branch master list
- [ ] Exact branch name
- [ ] Full address
- [ ] Google Maps pin / link
- [ ] Phone / mobile number
- [ ] Opening hours
- [ ] Branch photos
- [ ] Services available at each branch

## Services
- [ ] Official service name
- [ ] Approved description
- [ ] Duration
- [ ] Price or pricing rule
- [ ] Participating branches
- [ ] Pre/post-care copy approved by management
- [ ] Contraindication/safety copy reviewed by qualified company personnel if published

## Booking rules
- [ ] Walk-in vs reservation policy
- [ ] Time-slot rules
- [ ] Capacity per branch / per service
- [ ] Lead time
- [ ] Rescheduling policy
- [ ] Cancellation policy
- [ ] No-show policy
- [ ] Confirmation channel

## Promotions
- [ ] Promo title
- [ ] Exact dates
- [ ] Mechanics
- [ ] Participating branches/services
- [ ] Restrictions
- [ ] Approved poster/photo

## Legal / privacy
- [ ] Privacy policy
- [ ] Terms / booking terms
- [ ] Consent language
- [ ] Data retention rule
- [ ] Designated contact for privacy requests
