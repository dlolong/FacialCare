# The Executive Facial Care — Next.js Website Starter

A mobile-first **initial working website concept** for The Executive Facial Care, prepared from the promotional references supplied in the project discussion.

This is intentionally a **safe pre-proposal starter**: it does not invent official branch details, treatment claims, pricing, or backend behavior.

## Included

- Next.js App Router + TypeScript
- Responsive homepage inspired by the red / white / soft-beige brand direction
- Services page
- Branches page
- Promotions page
- Testimonials page
- Contact page
- Demo appointment booking flow
- Local demo imagery from the supplied references
- `AGENTS.md` with Codex development rules
- Sprint and owner-content checklists

## Quick start

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

> The package versions are declared broadly so you can install a current compatible Next.js 15 / React 19 setup. Commit your generated lockfile after the first successful install.

## Important before public launch

1. Replace demo imagery with company-approved originals.
2. Replace all placeholder branch information with the owner-confirmed master list.
3. Replace placeholder service descriptions with company-approved copy.
4. Confirm promo mechanics and dates before publishing.
5. Add privacy policy / terms before collecting real customer information.
6. Connect booking only after branch scheduling rules are documented.
7. Do not store medical or treatment-sensitive data in the initial booking form.
